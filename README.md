# 求职备战助手

一个本地化的求职准备网页工具，用来整理经历、围绕 JD 生成面试手册和知识体系，并按岗位归档。

## 功能

- 整理经历：通过 AI 追问生成简历条目、STAR 故事和面试素材
- 备战面试：粘贴 JD 后生成 JD 拆解、面试手册和知识体系
- 经历库：保存已整理经历，支持 PDF 简历导入
- 岗位库：按岗位保存面试手册、知识体系和聊天记录

## 数据说明

经历、岗位记录、面试手册、知识体系和 API Key 都保存在当前浏览器本地。清理浏览器数据、更换浏览器或设备、使用隐身模式时，本地数据可能会消失。重要内容建议复制到自己的文档备份。

调用 AI 时，请求内容会发送给用户在设置里选择的模型服务商。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
